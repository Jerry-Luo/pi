# NOTES（教学偏好备忘）

> 本文件记录用户对教学方式的明确偏好与工作约定，设计 lesson 时必须遵守。

## 语言与节奏
- 全程中文教学；所有学习文档用中文。
- 每次会话 60–90 分钟；一个源码项读不完保持"进行中"。
- 教学节奏固定：场景 → 讲解 → 定向阅读 → 推理 → 检查点。

## 教学法（用户明确要求）
- 只沿调用链顺序逐步讲解，不主动向学习者提问、不设置检查题；学习者有问题会主动提出。
- 因果、边界、调用链结论由导师直接给出，不留作猜题。
- 定向阅读必须直接给出：文件路径 + 最小完整源码 + 行号 + 逐行说明；不能让学习者自己找文件。
- 每次讲解 5–20 行；遇到函数调用先说明输入/输出/调用原因，控制流到达才进入函数体。
- 巩固方式（用户已确认）：聊天讲解保持直讲、不主动提问；HTML lesson 内提供**可选小测验**（`assets/quiz.js`，选项等长、即时反馈、可跳过）。测验永远不在聊天里发起。

## 版本与环境约定
- 仓库源码与本地安装的 pi 版本必须完全一致；不一致时立即提醒用户对齐，对齐前暂停用安装产物验证仓库行为。
- 行号不可跨版本沿用：每个符号先在当前版本源码重新定位（grep 符号定义），再讲解。
- 安装产物（dist/bundle）只用于确认入口与构建结果，学习一律以仓库 `src/` 为准。
- esbuild chunk 文件名不是稳定边界（已三次验证全部更名）。
- 不运行构建或测试；需要验证时把命令交给用户执行。

## 工作区结构约定
- 教学工作区 = `learning/pi-source-study/`（不在仓库根，避免污染产品库）。
- 进度唯一状态源 = `STUDY_STATE.md`（预写检查点协议见 README.md / RESUME_PROMPT.md）。
- teach skill 新增层：MISSION.md（使命）、RESOURCES.md（可信资源）、learning-records/（学习记录）、lessons/（HTML 课程单元）、reference/（速查表）、assets/（共享组件，首个 lesson 时创建）。
- CURRICULUM.md 的 11 课（00–10）是课程大纲；HTML lesson 是每个"源码项"的交付物，编号独立递增。

# 新会话恢复提示词

在 Pi 新会话中粘贴以下内容：

```text
继续仓库内 `learning/pi-source-study/` 的源码学习。请先完整阅读：
1. `learning/pi-source-study/README.md`
2. `learning/pi-source-study/STUDY_STATE.md`
3. `learning/pi-source-study/CURRICULUM.md` 中当前课时的完整章节
4. `learning/pi-source-study/LEARNING_NOTES.md` 中当前课时的已有笔记

严格以 `STUDY_STATE.md` 为进度唯一来源。开始每个源码项前先把“当前检查点”更新为该项和“进行中”；完成后立即勾选该项，记录带路径的已验证事实、待验证问题和下一项。每课按“场景 → 讲解 → 定向阅读 → 推理 → 检查点”进行：先解释具体执行链路和设计原因，再引导读取最小源码片段；只按调用链顺序逐步讲解，不主动向学习者提问或设置检查题，学习者有问题时会主动提出。不要跳到后续课时，不要修改产品源码，不要运行构建或测试。当前任务是：继续当前检查点所列源码项。
```

## 中途暂停时

在离开会话前请执行以下最小收尾：

1. 将当前项标为完成或进行中。
2. 写明最后读到的文件、符号或行号范围。
3. 写明下一项；若尚未完成当前项，下一项仍为当前项。
4. 追加一行会话日志。

突然离开且没有机会收尾时，新会话应从状态文件的“当前项”重新开始。课程要求在读每个项前预写当前项，因此不会因不确定进度而跳过内容。
